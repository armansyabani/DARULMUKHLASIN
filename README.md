✨ Tentang Project
KOPDES merupakan aplikasi web koperasi dengan konsep modern yang dibangun untuk membantu proses pengelolaan koperasi menjadi lebih terstruktur, efisien, dan mudah dikembangkan.
Project ini menggunakan arsitektur frontend modern dengan integrasi layanan backend/database sehingga dapat dikembangkan menjadi sistem koperasi yang lebih lengkap.
🔒 PRIVATE PROJECT — Source code ini tidak ditujukan untuk distribusi bebas. Pembelian, lisensi, penggunaan ulang, atau custom development dapat dibicarakan langsung dengan developer.

⚡ Instalasi
1. Clone Repository
git clone https://github.com/armansyabani/DARULMUKHLASIN.git
cd DARULMUKHLASIN
2. Install Dependency
Menggunakan npm:
npm install
atau Bun:
bun install
3. Konfigurasi Environment
Buat file:
.env
Isi sesuai konfigurasi layanan yang digunakan project.
⚠️ Jangan memasukkan credential atau secret ke repository publik.

4. Jalankan Development
npm run dev
atau:
bun run dev
🏗️ Production Build
npm run build
Preview:
npm run preview
